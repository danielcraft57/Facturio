# Outils OSINT pour Facturio

Collection complète d'outils OSINT pour l'intelligence d'entreprise.

## 🔍 Outils OSINT avancés
- **Shodan** : recherche d'infrastructures, serveurs, IoT
- **Censys** : cartographie des actifs numériques
- **VirusTotal** : analyse de réputation
- **HaveIBeenPwned** : vérification de fuites de données
- **DeHashed** : recherche dans les bases compromises

## 🔎 Recherche & Analyse
- **Google Dorks** : requêtes de recherche avancées
- **Wayback Machine** : archives historiques
- **BuiltWith** : technologies utilisées par les sites
- **Screaming Frog** : audit technique des sites

## 📊 Surveillance & Veille
- **Meltwater** : surveillance des médias
- **Crunchbase** : données startups et entreprises
- **LinkedIn Sales Navigator** : veille concurrentielle
- **SimilarWeb** : analyse du trafic web

## 🗺️ Géolocalisation
- **Google Earth Pro** : cartographie satellite
- **Foursquare** : données de localisation
- **Google My Business** : informations d'établissements

## 👥 Recherche de personnes
- **Pipl** : recherche de personnes, emails
- **ZoomInfo** : contacts B2B professionnels
- **Hunter.io** : recherche d'emails professionnels

## 💰 Informations financières
- **Bloomberg Terminal** : données financières
- **SEC EDGAR** : documents légaux US
- **Infogreffe** : registre du commerce français

## 🔧 Outils techniques
- **Puppeteer/Playwright** : scraping automatisé
- **Maltego** : analyse de liens et relations
- **Recon-ng** : framework de reconnaissance

## 🆓 Outils OSINT faciles d'accès (Gratuits/Pas chers)

### Recherche de base (Gratuits)
- **Google** : recherche avancée avec opérateurs
- **Bing** : recherche alternative, parfois meilleurs résultats
- **DuckDuckGo** : recherche privée, pas de tracking
- **Yandex** : moteur russe, résultats différents
- **Baidu** : moteur chinois, contenu asiatique
- **Qwant** : moteur européen, respect de la vie privée

### Vérification d'emails (Gratuits)
- **HaveIBeenPwned** : vérification de fuites de données
- **BreachDirectory** : vérification d'emails/passwords
- **Leak-Lookup** : vérification de compromissions
- **Holehe** : vérification d'emails sur différents services
- **EmailRep.io** : réputation d'emails

### Analyse de sites web (Gratuits)
- **BuiltWith** : technologies utilisées par les sites
- **Wappalyzer** : détection des technologies web
- **WhatRuns** : analyse des technologies de sites
- **Netcraft** : analyse de l'infrastructure web
- **SecurityHeaders.com** : analyse des en-têtes de sécurité

### Recherche de personnes (Gratuits)

- **FastPeopleSearch** : recherche de personnes gratuite
- **Radaris** : informations publiques et profils
- **Whitepages** : annuaires téléphoniques et adresses
- **Spokeo** : informations personnelles (limité gratuit)

### Informations d'entreprises (Gratuits)
