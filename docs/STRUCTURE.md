# Structure de la documentation

Organisation de la documentation Facturio par catégories.

## 📁 Structure des dossiers

```
docs/
├── README.md                    # Index principal
│
├── getting-started/            # 🚀 Démarrage rapide
│   ├── README.md
│   ├── INSTALLATION.md         # Guide d'installation
│   └── ENVIRONMENTS.md         # Configuration des environnements
│
├── api/                        # 📡 Documentation API
│   ├── README.md
│   └── API.md                  # Documentation complète des endpoints
│
├── development/                # 💻 Guides de développement
│   ├── README.md
│   ├── ARCHITECTURE.md         # Vue d'ensemble de l'architecture
│   ├── DEVELOPMENT.md          # Guide de développement
│   ├── CI_CD.md                # Intégration continue
│   └── OPTIMIZATION.md         # Optimisation des performances
│
├── modules/                     # 🔧 Modules spécialisés
│   ├── README.md
│   ├── OSINT.md                # Intégration OSINT
│   ├── SCRAPER.md              # Module de scraping
│   └── OSINT_TOOLS.md          # Liste des outils OSINT
│
├── planning/                    # 📅 Planning & Roadmap
│   ├── README.md
│   ├── ROADMAP.md              # Roadmap globale
│   ├── TODO.md                 # Liste complète des tâches
│   └── AVANCEMENT.md           # État actuel du projet
│
└── changelog/                   # 📝 Changelog & Notes
    ├── README.md
    ├── CHANGELOG_PRIORITES_HAUTES.md  # Changelog des priorités hautes
    └── NOTES_DEVELOPPEMENT.md         # Notes techniques
```

## 📚 Organisation par catégorie

### 🚀 Getting Started
Documentation pour démarrer rapidement avec Facturio.
- Installation et configuration
- Variables d'environnement
- Dépannage

### 📡 API
Documentation complète de l'API REST.
- Endpoints disponibles
- Exemples cURL
- Codes de statut
- Formats de réponse

### 💻 Development
Guides pour les développeurs.
- Architecture du projet
- Workflow de développement
- Tests et qualité
- CI/CD
- Optimisation

### 🔧 Modules
Documentation des modules spécialisés.
- OSINT et intelligence économique
- Scraping web
- Outils et intégrations

### 📅 Planning
Planning et roadmap du projet.
- Roadmap globale
- Liste des tâches (TODO)
- Avancement du projet

### 📝 Changelog
Historique des changements.
- Changelogs détaillés
- Notes de développement
- Décisions techniques

## 🔗 Navigation

Pour naviguer dans la documentation :
1. Commencer par [README.md](./README.md) pour l'index complet
2. Utiliser les README.md de chaque dossier pour une vue d'ensemble
3. Consulter les fichiers individuels pour les détails
