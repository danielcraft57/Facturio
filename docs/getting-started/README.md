# Démarrage rapide

Documentation pour démarrer rapidement avec PrestaFacture.

## 📚 Contenu

- [Installation](./INSTALLATION.md) - Guide complet d'installation
- [Configuration des environnements](./ENVIRONMENTS.md) - Variables d'environnement

## 🚀 Quick start

1. Installer les dépendances : `npm install`
2. Configurer la base de données : `npx prisma migrate dev`
3. Démarrer le serveur : `npm run start:dev`

Pour plus de détails, voir [Installation](./INSTALLATION.md).
