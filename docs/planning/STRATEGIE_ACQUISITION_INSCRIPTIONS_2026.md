## Positionnement

PrestaFacture = **outil vertical** pour prestataires du numérique (dev web, logiciel, automatisation, maintenance, IA).  
**Ne pas** concurrencer Pennylane / Indy sur compta complète + banque.

```
Compta + banque     →  Indy, Pennylane, Qonto
CRM PME générique   →  Sellsy, Axonaut, Evoliz
Vertical dev/auto   →  ★ PrestaFacture
```

## Concurrence (cartographie)

| Acteur | Forces | Faiblesse vs PrestaFacture |
|--------|--------|------------------------|
| **Indy** | Gratuit, PA intégrée, sync bancaire, URSSAF | Généraliste, peu orienté catalogue prestations tech |
| **Abby** | Micro-entreprise, time tracking, signature devis | Pas ciblé agences / intégrations API |
| **Pennylane** | SASU, expert-comptable, compte pro | Prix, surdimensionné pour freelance dev |
| **Qonto** | Banque + facturation | Hors vertical métier |
| **101+ PA** | Conformité réseau | Pas de couche métier devis/missions |

## Réglementation (leviers marketing)

| Date | Obligation |
|------|------------|
| **1er sept. 2026** | **Réception** e-factures — **toutes** entreprises assujetties TVA |
| **1er sept. 2026** | **Émission** — GE et ETI |
| **1er sept. 2027** | **Émission** — PME, TPE, micro |

- Formats : Factur-X, UBL, CII — via **Plateforme Agréée**.
- **E-reporting** : B2C, international, certains paiements.
- **ISCA** (anti-fraude TVA) : inaltérabilité, sécurisation, conservation 6 ans, archivage.

**Message clé** : la réception concerne **tout le monde** dès sept. 2026 — pas seulement l’émission 2027.

## Entonnoir acquisition

```
SEO + urgence sept. 2026 → Inscription Free → Onboarding 10 min + pack Dev
→ Première facture/devis → Upgrade Pro / Pro+e-facture → Rétention (missions, récurrence)
```

### 3 messages site / ads

1. *La facturation pensée pour les devs et intégrateurs — pas pour tout le monde.*
2. *Conforme facturation électronique 2026 : réception dès septembre, sans changer votre métier.*
3. *Devis → facture → FEC pour votre expert-comptable — en un seul outil léger.*

## Fonctionnalités « modernes » à communiquer

- Assistant conformité 2026 (score par facture)
- Catalogue prestations + packs importables
- Parcours forfait / acompte / maintenance / régie
- Export FEC, bases URSSAF
- Prospection ProspectLab (Pro)
- Portail devis/facture public + Stripe
- Réservation palier PA (Pro + e-facture)

**À ne pas promettre avant livraison** : sync bancaire temps réel, PA connectée, time tracking, e-reporting complet.
